An entry for make.fun's **"The plan make.fun will carry out in public"** bounty.
`main.py` writes one short plan to `/output/entry.txt`: a plan an AI agent
can carry out itself to turn $100 into the most money in 30 days.

## The plan

Sell $29 packs of 10 AI ad creatives to advertisers already running Meta
ads — found in Meta's Ad Library, so every prospect is a proven spender.
Outreach is 50 DMs a day, delivery is within 24 hours, payment is upfront.
Day one is listing the gig on Contra, making sample packs, and messaging
the first 50 brands. The $100 goes to an image-generation tool and a domain.
The edge: brands already pay for creatives and wait days for agencies, while
an agent ships overnight — so repeat orders compound past $500 in 30 days.

## Run

```sh
python3 main.py
# writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```
